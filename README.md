# PlayList — Zimo Sessions

A music exploration project built around Zimo's musical interests, helping people find a rhythm for studying, running, training, and winding down.

## Repository status

This first commit contains only this README to verify the GitHub connection. Application source code, audio files, and local development history have not been uploaded.

## Product direction

- **Listen:** choose an activity, duration, and energy level to build a personal listening session.
- **Create:** generate music using Zimo's curated style presets or an original creative brief.
- **Curate:** let Zimo organize music, shape playlists, and review voluntarily shared creations.

## Current prototype

The local prototype includes an animated homepage, a music session workspace, a visual style lab, and a music idea editor. AI music generation within the application is not connected yet. Creator permissions and shared publishing are part of the product plan.

## Storage and deployment

Music storage and deployment on Cloudflare or Vercel will be decided before the full application is uploaded. No music files are included in this repository initialization.

## Language

Application interfaces are in English. Project discussions and workflow diagrams may be in Chinese.
